What This Teaches New IT Engineers at EY:

  • Shift-Left Security: Automated testing and CVE vulnerability scanning happen before code can ever be packaged or deployed.
  • Zero-Credential Secrets Management: The workflow utilizes GitHub's native ephemeral GITHUB_TOKEN to authenticate directly with GHCR without storing permanent passwords.
  • Immutable Artifacts: Every single commit produces an exact, hash-pinned Docker image tag (e.g. sha-e7f41a9) ensuring absolute auditability for compliance.
  • Minimal Attack Surface: The multi-stage Docker build produces a hardened ~65MB container running as an unprivileged non-root user.
.github/workflows/ci-cd.yml (Excerpt) YAML 
jobs:
  test-and-lint:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: 20, cache: 'npm' }
      - run: npm ci
      - run: npm run lint
      - run: npm test

  build-and-push-ghcr:
    needs: test-and-lint
    runs-on: ubuntu-latest
    permissions:
      contents: read
      packages: write
    steps:
      - uses: docker/login-action@v3
        with:
          registry: ghcr.io
          username: ${{ github.actor }}
          password: ${{ secrets.GITHUB_TOKEN }}
      - uses: docker/build-push-action@v5
        with:
          push: true
          tags: ghcr.io/${{ github.repository }}:${{ github.sha }}
